1// The Host interfaces the desktop implements in Qt (rust-core-tasks.md §2.2, crates/ov-core/src/host.rs).
2//
3// Each class is a pure-virtual C++ mirror of one Rust Host trait. Implement them, hand them to
4// ov::new_client() as std::unique_ptr, and the core calls them back through cxx.
5//
6// Rules for implementations:
7// - Thread safety: the core may call any method from any thread that is inside a core call,
8// and concurrently. Guard shared state. (Qt: don't touch QObjects owned by another thread
9// without a queued/blocking connection.)
10// - Blocking: methods are synchronous. A call returns when the work is done (e.g. the HTTP
11// response has fully arrived). The core calls them from the worker thread that made the core
12// call, never from the thread that owns the UI unless the app calls the core from there.
13// - Errors: HttpTransport/ByteStream report transport failures through `failure` (kind + text)
14// and return a default-constructed value. Everything else reports errors by throwing; the
15// exception's what() may start with an ov wire code and ": " (e.g. "forbidden: keychain
16// locked") to choose the OvError code, otherwise the code is "internal".
17// - Secrets: values passed to SecureStore::set are secrets; wipe your copies.
18//
19// This header is included by the generated bridge before the shared structs are defined, so it
20// only forward-declares them. Include "ovcore.h" in your own code, not this file.

37// The body of an open server-sent-events stream (Rust `ByteStream`).
38class ByteStream {
39public:
40 virtual ~ByteStream() = default;
41 // The status the stream was opened with.
42 virtual std::uint16_t status() const = 0;
43 // Fills `chunk` with the next bytes and returns true, or returns false when the server
44 // closed the stream. On a transport failure, set `failure` and return false.
45 virtual bool next_chunk(rust::Vec<std::uint8_t> &chunk, TransportFailure &failure) const = 0;
46 // Closes the stream; later next_chunk calls return false.

50// HTTP (Rust `HttpTransport`): QNetworkAccessManager on the desktop. Must not follow redirects,
51// add cookies or log header values (they carry bearer tokens).
52class HttpTransport {
53public:
54 virtual ~HttpTransport() = default;

58 // Opens a server-sent-events stream. On failure set `failure` and return nullptr.
