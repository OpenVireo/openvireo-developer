openvireo-core-jvm

The OpenVireo core for Kotlin and Java 11+ on macOS, Linux and Windows (com.openvireo:openvireo-core-jvm): accounts, vaults, sync, share links and .kdbx files, on the same Rust code as the OpenVireo apps.

Start with the guide: Kotlin and Java. This reference is generated from openvireo-core at commit b56056f2e6c81d984c72ef8f3aae3f0a42fc8c43. Calling it from Java? See the /reference/java/.

com.openvireo.core
Link copied to clipboard
jvm

The binding itself, generated by UniFFI from the ov-ffi crate: OvClient, Account, Vault, ServiceAccount, SelfHosted, the records and enums they take and return, the Host interfaces (HttpTransport, SecureStore, BlobCache, Clock, LogSink), OvException and the free functions (crypto, share links, TOTP, OPAQUE). Network and disk calls are suspend functions; from Java, use the wrappers in com.openvireo.core.java.

com.openvireo.core.java
Link copied to clipboard
jvm

The API for Java, without coroutines: J<Object> wrappers (JOvClient, JAccount, JVault, ...) whose suspend methods return CompletableFuture, JOv (every free function as a static), JRecords (records with unsigned fields), JErrors, and the future-based Host interfaces with JHosts and JDefaultHosts. Generated from the binding on every build, so it can't drift from it.
