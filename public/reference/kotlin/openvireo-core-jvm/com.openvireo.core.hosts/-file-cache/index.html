FileCache

class FileCache @JvmOverloads constructor(val dir: Path, dispatcher: CoroutineDispatcher = Dispatchers.IO) : BlobCache(source)

A BlobCache in files under dir (the offline cache, SPEC §20). Everything the core stores here is ciphertext or public, so ordinary app storage is fine (an app's cache or data directory).

Layout: <dir>/u<hex(userId)>/vaults/<hex(vaultId)>.vault and <dir>/u<hex(userId)>/meta/<hex(name)>.bin. Names are hex so any id is a safe file name; the per-device records (userId == "") live under <dir>/u/. Writes go to a temporary file and are moved into place, so a crash leaves the old record or the new one. The I/O runs on dispatcher.
