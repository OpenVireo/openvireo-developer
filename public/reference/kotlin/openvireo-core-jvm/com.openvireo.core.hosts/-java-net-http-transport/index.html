JavaNetHttpTransport

class JavaNetHttpTransport @JvmOverloads constructor(client: HttpClient = defaultClient(), requestTimeout: Duration? = Duration.ofSeconds(60)) : HttpTransport(source)

The default HttpTransport on the JVM: java.net.http.HttpClient (JDK 11+), fully asynchronous.

As ov_core::host::HttpTransport requires:

  • No redirects: the client is built with Redirect.NEVER, so a 3xx comes back as a response and the core refuses it. A client passed in must be built the same way.

  • No cookies: the client has no CookieHandler (a client passed in with one is refused).

  • Any status is a response: 4xx/5xx come back with their body, never as an exception.

  • Headers: the request's headers, in order, plus what the platform always adds (User-Agent, Host, Content-Length). The headers java.net.http reserves for itself (Connection, Content-Length, Expect, Host, Upgrade) are left to it. Header values may be bearer tokens and are never logged.

  • Errors: no network, DNS failure or connection refused → TransportException.Offline, a timeout → Timeout, TLS → Tls, anything else → Other.

  • Streams (openStream, server-sent events): the response comes back when its headers arrive, and nextChunk hands over each piece of the body as it is received.

requestTimeout bounds the wait for a response's headers (null waits forever).
