defaultHost

@JvmOverloads
fun defaultHost(cacheDir: Path? = null, http: HttpTransport = JavaNetHttpTransport(), store: SecureStore = MemoryStore(), cache: BlobCache = cacheDir?.let { FileCache(it) } ?: MemoryCache(), clock: Clock = SystemClock, log: LogSink = JulLogSink()): Host(source)

A Host from the default parts, each replaceable: JavaNetHttpTransport, a MemoryStore (a new device every run: pass a persistent SecureStore to keep sessions and trusted Secret Keys), a FileCache under cacheDir (or a MemoryCache when it is null), SystemClock and JulLogSink.
