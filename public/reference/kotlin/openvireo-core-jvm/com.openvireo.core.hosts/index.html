JulLogSink
Link copied to clipboard
class JulLogSink @JvmOverloads constructor(baseName: String = "openvireo") : LogSink

A LogSink that forwards the core's log lines to java.util.logging, on the logger <baseName>.<target> (openvireo.ov_sync, ...), so they can be filtered per module or bridged to SLF4J/Log4j with the usual JUL bridges. Levels: error → SEVERE, warn → WARNING, info → INFO, debug → FINE, trace → FINER. The core never logs secrets.

MemoryCache

class MemoryCache : BlobCache

A BlobCache in memory: the offline cache (SPEC §20) lasts as long as the process. Everything in it is ciphertext or public. Safe to call concurrently.

MemoryStore
Link copied to clipboard
class MemoryStore : SecureStore

A SecureStore in memory: nothing survives the process, so every run is a new device (sessions and trusted Secret Keys are forgotten). Good for scripts, servers that sign in each time, and tests. Values are copied in and out; removed and replaced values are wiped. Safe to call concurrently.
