JDefaultHosts

object JDefaultHosts(source)

The JVM's default Host parts for Java (the same as Kotlin's defaultHost): JavaNetHttpTransport, a MemoryStore (a new device every run: set a persistent store to keep sessions), a FileCache under a directory or a MemoryCache, SystemClock and JulLogSink.

JOvClient client = new JOvClient(config, JDefaultHosts.create(Path.of("ov-cache")));
Host custom = JDefaultHosts.builder().store(myKeychainStore).build();
