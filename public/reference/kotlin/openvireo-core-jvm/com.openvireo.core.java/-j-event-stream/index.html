The Java facade of com.openvireo.core.EventStream: every suspend method returns a CompletableFuture that runs on scope (cancelling the future cancels the call), objects come back as J wrappers on the same scope, and unsigned numbers are the next wider signed type. unwrap gives the generated object; close frees it.
