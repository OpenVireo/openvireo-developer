openvireo.hosts

Ready-made Host parts, so a script needs no glue.

The core never opens a socket or a file, reads the clock or touches a keychain itself: it calls the five Host interfaces (HttpTransport, SecureStore, BlobCache, Clock, LogSink). This module implements each of them on the standard library (plus two optional extras), and default_host() bundles them::

import asyncio, openvireo
from openvireo.hosts import default_host

async def main():
    client = openvireo.OvClient(
        openvireo.ClientConfig(
            device=openvireo.DeviceInfo(id=None, name="script", platform=openvireo.Platform.CLI),
            offline=False,
            server=None,
        ),
        default_host(cache_dir="~/.cache/openvireo"),
    )
    account = await client.connect("https://accounts.openvireo.com", openvireo.CancelToken())

The async methods run on the event loop that awaits the core call. Blocking work (urllib, files, the keyring) goes through asyncio.to_thread(), so it never stalls that loop.

Secrets that cross into Python (passwords, Secret Keys, stored session tokens) are plain bytes. Python can't wipe them; the core zeroizes its own copies.

class FileCache(openvireo._core.ov_ffi.BlobCache):

The offline cache (SPEC §20) as files under directory.

Everything the core caches is already ciphertext or public (vault blobs under the vault key, the wrapped keyset, the discovery document), so plain files are fine. Layout, with every id hex-encoded so no id can escape the folder::

<directory>/<hex user id or "_device">/vaults/<hex vault id>.json
<directory>/<hex user id or "_device">/meta/<hex name>

Writes are atomic (a temporary file, then os.replace); folders are created 0700 and files 0600.

class HttpxTransport(openvireo._core.ov_ffi.HttpTransport):

Async HTTP on httpx (pip install openvireo[httpx]).

Same contract as UrllibTransport: no redirects (follow_redirects=False), a cookie jar that refuses every cookie, the core's headers plus User-Agent and httpx's own (Accept, Accept-Encoding, Connection), every status a response. Streams are read natively (aiter_raw), with no worker thread.

An httpx.AsyncClient is tied to the event loop that made its connections, so the transport keeps one client per running loop. Pass client to use your own (it must not follow redirects or keep cookies); timeout applies to the clients this class makes, streams read without one.

class KeyringStore(openvireo._core.ov_ffi.SecureStore):

Secrets in the OS keychain through keyring (pip install openvireo[keyring]): the macOS Keychain, Windows Credential Locker, or the Secret Service on Linux. Each key is an entry of service; values are stored base64-encoded.

A keychain that can't be read raises OvError (code internal), which the core treats differently from a missing value.

Forwards the core's log lines to logging.getLogger("openvireo") (or logger). The core's module (e.g. ov_sync) is in the record as ov_target. The core never logs secrets. It may call this from any thread.

class UrllibTransport(openvireo._core.ov_ffi.HttpTransport):

HTTP on the standard library (urllib.request), run through asyncio.to_thread().

As the contract requires (ov_core::host::HttpTransport):

  • redirects are not followed: a 3xx comes back as a response, like any other status;
  • no cookies are stored or sent, and no credentials are added;
  • the core's headers are sent as given, plus User-Agent (user_agent()) when the core doesn't set one, and what http.client always adds (Host, Content-Length, Accept-Encoding: identity). Header values may be bearer tokens and are never logged;
  • any status is a response; only a failure to get one raises TransportError (Offline for refused connections and DNS failures, Timeout, Tls, Other).

timeout (seconds) bounds connecting and each read of send(). Streams (open_stream(), the SSE events) use stream_timeout, None by default because an event stream can be quiet for a long time; closing the stream unblocks a pending read. Proxies come from the environment (HTTPS_PROXY …) unless proxies is given ({} for none). ssl_context replaces the default verified context.

def default_host( *, http: openvireo.HttpTransport | None = None, store: openvireo.SecureStore | None = None, cache: openvireo.BlobCache | None = None, clock: openvireo.Clock | None = None, log: openvireo.LogSink | None = None, cache_dir: str | os.PathLike[str] | None = None) -> openvireo.Host:

A Host from the parts given, with defaults for the rest:

  • http: default_transport() (httpx if installed, else urllib);
  • store: MemoryStore (pass KeyringStore to keep sessions across runs);
  • cache: FileCache on cache_dir if given, else MemoryCache;
  • clock: SystemClock; log: LoggingSink.
