The facade: the only API the bindings (ov-wasm, ov-ffi, ov-ffi-cpp) and the ov CLI see.

Frozen contract (rust-core-tasks.md §2.3, tag contract-v1; later additions up to contract-v1.6 are listed in docs/adr/0001-contract.md): the names, signatures and records in this module don’t change without a CONTRACT-REQUEST. The method bodies (W2-A) only orchestrate: they call the domain crates through crate::impls.

The API has one Rust method for each public method of the TypeScript SDK’s Account, AccountVault, ServiceAccount and SelfHostedSync and of the iOS app’s Account and its extensions; docs/api-coverage.md maps every one.

Binding rules (§2.3):

  • Types that cross FFI are plain records and enums: no generics, lifetimes or trait objects except the Host traits. Handles (OvClient, Account, Vault, ServiceAccount, SelfHosted, EventStream, TotpChallenge) are cheap Clone objects (an Arc inside) that are safe to share between threads.
  • Secrets cross as Vec<u8> (SecretBytes, UTF-8 for text). The core wipes the inputs it is given; the caller wipes the outputs it receives.
  • Every fallible call returns Result<T, OvError>; bindings turn a panic into OvError { code: Internal }.
  • Calls that may touch the network or run a KDF are async and take a CancelToken. A cancelled call returns aborted.
