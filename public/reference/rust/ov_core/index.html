openvireo-core: the client side of the OpenVireo protocol (accounts, vaults, sharing, share links, sync) in one Rust crate that every client calls: web and the extension through WASM, iOS through Swift, the desktop through C++, and the ov CLI natively (rust-core.md).

  • api: the facade the bindings expose. Start at api::OvClient.
  • host: the traits each platform implements (HTTP, secure storage, offline cache, clock, logs). The core does no I/O of its own.

Both modules are the frozen contract-v1 (rust-core-tasks.md §2.2, §2.3).
