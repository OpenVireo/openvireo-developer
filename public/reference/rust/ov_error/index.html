OvError, the one error type every openvireo-core API returns.

OvErrorCode lists the TypeScript SDK’s OpenVireoErrorCode values one for one (packages/sdk/src/errors.ts), plus the codes the SDK throws without listing them and OvErrorCode::Internal for a panic caught at a binding edge. Every code has a stable wire string ("plan_limit") that bindings expose, so UI code written against the TS SDK keeps matching on the same strings.

Server errors use the {error, code} body of openapi.yaml. A server code that isn’t one of these variants keeps its exact string in OvError::server_code, and the variant comes from the HTTP status (the SDK’s codeForStatus), so OvError::wire_code still returns what the server sent.
