The Host: everything the core asks the platform to do (rust-core.md §5).

Frozen contract (rust-core-tasks.md §2.2, tag contract-v1; moved unchanged from ov_core::host into this crate in contract-v1.5 so ov-sync and ov-vault can use it without depending on ov-core, which re-exports it as ov_core::host). The core never opens a socket or a file, reads the clock or touches the Keychain itself. Each platform implements these traits once (URLSession + Keychain on iOS, QNetworkAccessManager + DPAPI/libsecret on desktop, fetch + IndexedDB on the web, reqwest + files in the ov CLI) and passes a Host to ov_core::api::OvClient::new.

Randomness is not part of the Host: the core reads the platform CSPRNG through getrandom (crypto.getRandomValues on wasm32).

Async traits use async_trait. On wasm32 the futures and trait objects are not Send (async_trait(?Send), and MaybeSend/MaybeSync are empty), because JS values can’t cross threads; everywhere else they are Send + Sync.
