Expand description

The offline cache (SPEC §20): per user, per vault, plus a few per-user and per-server records.

Records are keyed by user_id because two accounts on one device can share a vault (SPEC §21). The meta_* records hold what offline unlock and listing need: the discovery document (user_id is then "" and name is config:<issuer>), and per user the wrapped keyset + KDF (profile) and the vault list as the server returned it (vaults). All of it is ciphertext or public.
