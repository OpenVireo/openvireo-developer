1//! openvireo-core: the client side of the OpenVireo protocol (accounts, vaults, sharing, share
2//! links, sync) in one Rust crate that every client calls: web and the extension through WASM,
3//! iOS through Swift, the desktop through C++, and the `ov` CLI natively (rust-core.md).
4//!
5//! - [`api`]: the facade the bindings expose. Start at [`api::OvClient`].
6//! - [`host`]: the traits each platform implements (HTTP, secure storage, offline cache, clock,
7//!   logs). The core does no I/O of its own.
8//!
9//! Both modules are the frozen `contract-v1` (rust-core-tasks.md §2.2, §2.3).
10
