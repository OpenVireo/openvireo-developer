## Versions

The core and the SDK follow [Semantic Versioning](https://semver.org). A minor release (1.2) adds API, a
patch release (1.2.1) fixes or repackages, and only a major release (2.0) removes or changes API. So these
docs work for any 1.x release you're on, as long as you skip what arrived after it: a page marks that
with a badge, like <span class="ov-since ov-since-added">Added in 1.1</span>.

Every binding has the core's version. The SDK has its own version, and each SDK release says which core it
is built on. The sync server is still 0.x, so a minor release can change its API; its changelog says when
one does.
